# GestionDeEncuentrosDeportivos

El proyecto consta en desarrollar una aplicación que permita a usuarios de la misma, formar equipos para poder jugar un partido deportivo en la ciudad de Rosario.
Cada usuario podrá crear partidos de cualquier tipo de deporte, en un horario y fecha determinada, unirse a partidos ya creados, invitar a otros jugadores a un partido, y además ver reportes de la actividad en la aplicación.
